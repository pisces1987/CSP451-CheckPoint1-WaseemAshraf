CSP451 CheckPoint 1 - Version Control Exercise

Description

This project is part of the CSP451 (DevOps and Cloud-Adjacent Topics) course at Seneca College. It demonstrates proficiency in using Git for version control, implementing a feature-branch workflow, and utilizing the GitHub CLI for cloud repository management.

Installation

Ensure you have Git and GitHub CLI installed on your machine.

Clone this repository:

git clone [https://github.com/pisces1987/CSP451-CheckPoint1-WaseemAshraf.git](https://github.com/pisces1987/CSP451-CheckPoint1-WaseemAshraf.git)


Navigate to the project directory:

cd CSP451-CheckPoint1-WaseemAshraf


Usage

Open index.html in any modern web browser to view the landing page.

Check the browser's developer console (F12) to see the JavaScript output.

Useful Git commands for this project:

git log --oneline --graph --all (View history)

git status (Check local changes)

Contributing

We follow the Feature Branch Workflow:

Create a branch: git checkout -b feature/your-feature-name

Commit changes using Conventional Commits (e.g., feat:, fix:, docs:).

Push to origin and open a Pull Request.
